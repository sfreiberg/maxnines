Proxies

A proxy or load balancer in front of MaxNines passes on each person's address in an X-Forwarded-For header. Anyone can send that header, so MaxNines only believes it from a proxy you trust. Until then, it sees every person at the proxy's address: one person's wrong passwords can lock everyone out for a minute, and the audit log can't say where anyone was.
