How to get a PagerDuty integration key
  1. In PagerDuty, open the service that should get these alerts, then its Integrations tab.
  2. Add an integration, and choose Events API V2.
  3. Copy its Integration Key into the box above.

Sending a test opens an incident on that service and resolves it straight away, which can notify whoever is on call.

How to set up AlertOps
  1. In AlertOps, go to Configuration, then Integrations. Under Inbound Integrations, choose API and add one using the Custom card, with the escalation policy you want.
  2. Open its rules for opening and closing an alert. Keep the method as POST and the content as JSON.
  3. Paste this in as the sample data: 
    {{ alertops_sample }}
  4. Map alert_id to both Source Name and Source Id, so each alert stays separate. A fixed Source Name would merge them into one.
  5. Map status as the status field. Open an alert when it contains open, and close it when it contains closed.
  6. Map subject and message to the text fields you want, and link to Source URL.
  7. Leave the authorization header off, then copy the integration's URL into the box above. Do this last, as changing its source changes the URL.

Sending a test opens an alert and closes it straight away, which can notify whoever is on call.

How to get a SIGNL4 webhook URL

Put https://connect.signl4.com/webhook/ followed by your SIGNL4 team or integration secret in the box above.

Sending a test opens an alert and resolves it straight away, which can notify whoever is on call.

How to set up a Telegram bot
  1. In Telegram, message @BotFather, send /newbot, and follow its steps. Copy the token it gives you into the box above.
  2. Add the bot to the group that should get alerts, or send the bot a message yourself for alerts in a private chat. For a channel, make the bot an admin that can post.
  3. To find the chat ID, open https://api.telegram.org/bot followed by the token and /getUpdates in a browser, and look for "chat":{"id":. Group IDs start with a minus sign. A public channel can use its @username instead.

When an alert resolves, the message replies to the one that said it started.

How to create the Slack app
  1. At api.slack.com/apps, choose Create New App, then From a manifest.
  2. Pick your workspace and paste this in: 
    display_information:
  name: MaxNines
features:
  bot_user:
    display_name: maxnines
oauth_config:
  scopes:
    bot:
      - chat:write
      - chat:write.public
      - users:read
      - users:read.email
settings:
  interactivity:
    is_enabled: true
  socket_mode_enabled: true
  3. Install the app to your workspace, then copy its bot token here. It starts with xoxb-.
  4. For buttons, open Basic Information, then App-Level Tokens. Generate one with the connections:write scope, and copy it into the app-level token box. It starts with xapp-.
  5. For a private channel, invite the app to it first.
  6. On an Enterprise Grid org-wide install, use the channel's ID rather than its name. It's at the bottom of the channel's details in Slack.

Buttons act as the MaxNines user with the same email address as the person pressing them. Slack guests and people from other organizations can't use them. The server connects out to Slack for them, so it doesn't need to be reachable from the internet.
