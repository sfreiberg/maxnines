# Security

## Reporting a problem

Please email [security@maxnines.com](mailto:security@maxnines.com) rather than
opening an issue or a discussion, so the problem isn't public before there's a fix.

It helps to include:

- what you found, and what someone could do with it;
- the steps to see it happen, or a proof of concept;
- which versions you tried, which `maxnines-server version`, `maxnines-agent version`
  and `maxnines --version` print;
- anything about your setup that matters, such as the operating system, the main
  database, the metrics database, or running behind a proxy.

You'll get a reply to say it arrived, then updates as it's looked into and fixed.
Please give a fix time to be released before telling anyone else. You'll be credited
in the release notes, unless you'd rather not be.

## Supported versions

MaxNines is in early pre-releases, so fixes go into the next release only. Upgrade
to it rather than expecting a fix for an older one.

## What's covered

The server, the agent and the command line in this repository, and the releases
built from it. Problems in a dependency are welcome too, if they affect MaxNines.
